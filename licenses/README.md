# Licences and checksums

This folder holds the licence texts of everything AI Music includes or can download, and a SHA-256 checksum of every recorded sound file in the sound packs.

- `*-CC0-1.0.txt`: the licence file of each recorded-sound library (CC0 1.0 Universal, public domain).
- `*.sha256`: one line per file, `checksum  path`, with the path relative to that library's folder (or to the sound folder). They let anyone confirm that a pack holds the original, unchanged recordings.
- `surge-xt-renders.txt`: how the synthesizer recordings were made, and why they are free to share.
- `go-modules.txt`: licence texts of the Go modules compiled into the app.

The credits are in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
